# RoadQuiz marketing artwork

The selected Gumroad artwork is maintained as editable SVG source and reuses
the production RoadQuiz character files from `public/characters`.

| Asset | Canvas | Use |
| --- | ---: | --- |
| `cover-characters.svg` | 1600 × 900 | Gumroad product cover |
| `thumbnail-characters.svg` | 600 × 600 | Gumroad Library, Discover and profile thumbnail |

Both assets use the product's Inter-based visual language and the approved
headline, “Turn your trip into a game show.” The cover keeps the driver out of
gameplay and carries the passenger-only safety cue.
